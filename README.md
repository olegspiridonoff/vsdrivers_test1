# SVdrivers - Система учёта доходов и расходов водителей такси

## Описание

Веб-приложение для еженедельного учёта доходов и расходов водителей такси с ролевой моделью, аналитикой и аудит-логированием.

## Демо-версия (фронтенд)

Текущая версия работает как SPA на React с localStorage (эмуляция БД).

### Демо-аккаунты:
- **Администратор**: admin@taxi.ru / admin123
- **Руководитель**: manager@taxi.ru / manager123
- **Водитель**: driver1@taxi.ru / driver123

## PHP + MySQL развёртывание

Для полноценного развёртывания с MySQL:

1. Импортируйте `public/database.sql` в MySQL
2. Создайте PHP-бэкенд с PDO подключениями
3. Замените localStorage на API-запросы к PHP-скриптам

### Структура PHP-проекта:
```
/api
  /config/database.php    - PDO подключение
  /auth/login.php         - Авторизация
  /auth/register.php      - Регистрация
  /reports/create.php     - Создание отчёта
  /reports/update.php     - Обновление отчёта
  /reports/delete.php     - Удаление отчёта
  /reports/list.php       - Список отчётов
  /users/list.php         - Список пользователей
  /users/create.php       - Создание пользователя
  /users/update.php       - Обновление пользователя
  /users/delete.php       - Удаление пользователя
```

## Роли и права доступа

| Функция | Водитель | Руководитель | Администратор |
|---------|----------|-------------|---------------|
| Просмотр своих отчётов | ✅ | ✅ | ✅ |
| Создание отчётов | ✅ (свои) | ✅ (любые) | ✅ (любые) |
| Редактирование отчётов | ❌ | ✅ (с аудитом) | ✅ (с аудитом) |
| Удаление отчётов | ❌ | ❌ | ✅ |
| Аналитика | ❌ | ✅ (все водители) | ✅ (все) |
| Управление пользователями | ❌ | ❌ | ✅ |
| Экспорт CSV | ❌ | ✅ | ✅ |

## Формула расчёта выплаты

```
Итого = (Wheely × 0.30) + (Яндекс × 0.35) + (Собств. аренда × 0.30) + (Часы × 500₽) + Компенсации + Бонусы - Вычеты
```

## Технологии

- **Frontend**: React, TypeScript, Tailwind CSS, Chart.js, Lucide Icons
- **Backend (для PHP-версии)**: PHP 8+, PDO, MySQL 8+
- **Безопасность**: password_hash(), Prepared Statements, XSS-защита (htmlspecialchars)
